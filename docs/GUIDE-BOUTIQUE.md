# Gérer la boutique — guide pour The Roots Corner

Tout se fait dans **l'administration Shopify** : admin.shopify.com.
Le site se met à jour tout seul, **toutes les 3 heures**. Une pièce vendue
apparaît « Vendue » sur le site **immédiatement**.

---

## Ajouter une nouvelle pièce

**Produits → Ajouter un produit**

| Champ | Quoi mettre |
|---|---|
| Titre | Le nom de la pièce |
| Description | Ce que vous savez de la pièce — matière, dimensions, origine **si vous la connaissez**. Rien d'autre. |
| Médias | Les photos. La première est la photo principale. Mettez-en plusieurs : la pièce entière, un détail de la matière, une photo qui montre la taille. |
| Prix | Le prix TTC en euros |
| Inventaire | **Suivre la quantité** coché · Quantité **1** · « Continuer à vendre en cas de rupture » **décoché** |
| Type de produit | Choisissez la pièce du site : **Tabourets & sièges · Pièces africaines · Pots & contenants · Céramiques de Tamegroute · Vases · Objets · Lumière · Tapis** |
| Statut | **Actif** |
| Canaux de vente | **Boutique en ligne** coché |

Le **Type** est important : c'est lui qui range la pièce dans la bonne
catégorie du site. Sans Type, la pièce n'apparaît pas sur le site.

## Changer un prix

Produits → la pièce → Prix → Enregistrer. Visible sur le site au plus tard
3 heures après.

## Une pièce est vendue ailleurs (en boutique, sur Instagram…)

Produits → la pièce → Inventaire → mettez **0**. Elle passe « Vendue » sur le
site et ne peut plus être achetée.

## Retirer une pièce du site

Produits → la pièce → Statut **Brouillon**.

## Une commande arrive

1. Vous recevez un e-mail de Shopify. Le client reçoit sa confirmation
   automatiquement.
2. **Commandes → la commande** : adresse, téléphone, pièce, montant payé.
3. Quand le colis part : **Traiter l'article → numéro de suivi du transporteur
   → Traiter**. Le client reçoit automatiquement l'e-mail « votre commande est
   expédiée » avec le lien de suivi, et le voit dans **Mes commandes** sur le
   site.

⚠️ Sans cette étape 3, le client voit sa commande « non expédiée » pour
toujours.

## Les frais de livraison

**Paramètres → Expédition et livraison**. Ce sont les tarifs de votre propre
page « Livraison » : Maroc 25 €, International 50 €, 80 € à partir de 200 €.
Vous pouvez les modifier ici à tout moment.

> À vérifier : aujourd'hui une commande de 200 € ou plus paie **plus** de
> livraison (80 €) qu'une petite (50 €). C'est ce que dit votre page actuelle
> — dites-nous si c'est voulu.

## Le texte des pages du site

Les textes (histoire, tapis Mrirt, mentions légales…) ne se modifient pas dans
Shopify. Envoyez-nous le changement et nous le faisons.

## Les séries de tapis Mrirt

Chaque **série** est un produit dans la collection **Tapis Mrirt**
(Produits → filtrer par type « Tapis Mrirt »), comme sur benirugs.com.

| Pour… | Dans Shopify |
|---|---|
| Renommer une série | Ouvrir le produit → **Titre** |
| Ajouter une couleur | Options → **Couleur** → ajouter une valeur, ex. « Terracotta + Brun chocolat + Taupe » |
| Ajouter une taille | Options → **Taille** → ajouter une valeur, ex. « 200 × 300 cm » |
| Mettre une photo de la couleur | Variante → image. Sinon la pastille est dessinée d'après les mots de la couleur. |
| Nouvelle série | **Dupliquer** une série existante, puis la renommer. Le **Type de produit** doit rester « Tapis Mrirt ». |

Le formulaire de la page Tapis Mrirt se met à jour tout seul (en quelques minutes).
Ces tapis restent **sur demande** : ils ne peuvent pas être achetés directement
tant que le prix est à 0 et le stock à 0.

⚠️ Les 4 séries actuelles (Uni, Lignes, Losanges, Graphique) sont des
**exemples** : remplacez-les par vos vraies séries.
